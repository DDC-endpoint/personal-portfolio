## How V3 ships

1. `v3` is the integration branch, cut from `main` at `8cad99b`, just after PR #3.
2. Each phase gets its own branch off `v3` and a PR **into `v3`**, never into `main`.
3. After every merge, test `v3` locally: golden path, mobile, reduced motion, and a Lighthouse mobile run on a production build.
4. When all four phases are in, `v3` merges to `main`, which triggers the site redeploy.

The phases:

1. Motion system, loader, Hero (ASCII portrait), cursor lens, Marquee removal.
2. Projects: the diagonal skeleton showcase.
3. Timeline, Lens (gallery) and Contact.
4. Copy refresh, quiet-section upgrades (Leadership, Skills terminal), `/services` and the page transition.

## How Damian likes to work (from this session)

- **Many questions, as multiple choice.** Up to four at a time, with a recommended option first and room for his own answer. He often answers with "Other" and a short note, so read those answers carefully.
- **Show, don't describe.**
  - Visual questions get a live prototype in the browser: run `spike/serve.cjs`, then open the page for him.
  - Before showing anything, verify it yourself with headless screenshots (desktop 1440×900, mobile 390×844, dark mode).
- **References are narrow.** A shared reference (video, screenshot, site) targets one element only; don't restyle anything else from it. Ask before borrowing more.
- **Keep the site's existing style:** light-blue palette, Instrument Serif, JetBrains Mono, Manrope. He rejects anything that "feels AI coded".
- **Record everything:**
  - Every decision goes into `docs/v3/` straight away.
  - Commit locally on `v3` with a clear message.
  - Don't push or open PRs unless asked.
- **Public repo hygiene (CLAUDE.md):** no photo originals, CV, infra details or secrets. Scan the staged diff before every commit.

## Running the prototypes

From the repo root:

```bash
node docs/v3/spike/process-headshot.cjs "<path to the studio headshot PNG>" docs/v3/spike   # → spike/cutout.png
node docs/v3/spike/make-gallery-copies.cjs                                              # → spike/gal/f01–f10.jpg
node docs/v3/spike/serve.cjs                                                            # http://localhost:3200
```

Then open `/portrait-spike.html`, `/hero-live.html` or `/gallery-mockup.html`. All generated images are gitignored.

For headless screenshots, the installed Playwright may want a newer Chromium build than the one on disk. Point `chromium.launch({ executablePath })` at the installed build instead of downloading.

## Ground rules (from CLAUDE.md, still in force)

- **Public repo:** never commit raw photo originals, the CV, infrastructure details or secrets.
